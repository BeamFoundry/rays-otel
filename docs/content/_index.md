# BeamFoundry Rays OTel

**Rays OTel** is the official OpenTelemetry integration package for the **BeamFoundry Rays** framework.
It provides a configurable OpenTelemetry SDK environment—auto-configuring traces, metrics, logs, propagators,
an `otelhttp`-instrumented `*http.Client`, and a `log/slog` bridge—while keeping `rays` core dependency-light.
